# Learn JavaScript: 
## project 1 : To-Do List Project

Welcome to the beginner-friendly To-Do List project! This project was built from scratch with the primary goal of **learning JavaScript**. The code is heavily commented to explain every single step, making it the perfect resource if you're just starting your web development journey.

## 🚀 Features
- **Add Tasks**: Type a task and hit "Enter" or click the "Add" button to append it to your list.
- **Delete Tasks**: Click the "Delete" button next to any task to remove it.
- **Mark as Complete**: Click on the text of any task to strike a line through it, marking it as done.
- **Data Persistence**: Tasks are saved locally to your browser's memory (`localStorage`). If you refresh or close the page, your tasks will still be there when you come back!

## 🧠 Key JavaScript Concepts Learned
By reading through the `script.js` file, you will learn about:
- **DOM Manipulation**: How to select HTML elements (`getElementById`, `querySelector`) and create new ones (`createElement`).
- **Event Listeners**: How to make your page respond to mouse clicks and keyboard presses (`addEventListener`).
- **Variables & State Management**: How to use a JavaScript Array of Objects (`[{ text: "Buy milk", completed: false }]`) to store your application's data.
- **Rendering**: How to draw and update the screen based on the data in your state array.
- **Browser Storage**: How to save your data across sessions using `localStorage` along with `JSON.stringify()` and `JSON.parse()`.
